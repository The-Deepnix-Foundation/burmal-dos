# Burmal-DOS

Burmal-DOS - это кастомный дистрибутив операционной системы от The Deepnix Foundation. Проект объединяет классическую консольную среду с собственным пакетным менеджером (`dpx`), модульным оформлением, графической оболочкой на Python и удобными средствами сборки.

## Структура репозитория

В репозитории содержатся следующие компоненты:

* `branding/` - Оформление системы: splash-экраны, баннеры, конфигурации `fastfetch` (включая компактный вид), файлы приветствия (`issue`, `motd`) и `os-release`.
* `build/` - Инструменты сборки: Dockerfile, скрипт создания ISO (`build-iso.sh`) и скрипт пост-настройки (`burmal-postsetup.sh`).
* `dpx/` - Фирменный пакетный менеджер `dpx` и пример конфигурации.
* `gui/` - Графический интерфейс на Python (`burmal-gui.py`), менеджер сессий и бинарные компоненты.
* `installer/` - Скрипт установки системы (`burmal-installer.sh`).

## Основные компоненты

1. **Брендинг и конфиги:** Полностью настраиваемый визуальный стиль при старте системы, кастомный `fastfetch` и приветственные сообщения.
2. **Пакетный менеджер `dpx`:** Легковесный инструмент для управления пакетами и репозиториями ОС.
3. **Графическая оболочка:** Легкий интерфейс на Python (`burmal-gui`) для работы в оконном режиме.
4. **Сборка через Docker и скрипты:** Возможность собирать систему в изоляции с помощью Docker или напрямую запускать генерацию ISO-образа.
5. **Установщик:** Автоматизированный скрипт для развертывания системы на целевой машине.

## Сборка и установка

### Клонирование

```bash
git clone https://github.com/The-Deepnix-Foundation/burmal-dos.git
cd burmal-dos
```

### Сборка через Docker

Для сборки внутри контейнера используйте скрипты из папки `build/`:

```bash
cd build
./docker-build.sh
```

Либо запустите генерацию ISO напрямую в подходящем окружении:

```bash
./build-iso.sh
```

### Установка

Для установки системы запустите скрипт из папки `installer/`:

```bash
cd installer
sudo ./burmal-installer.sh
```
